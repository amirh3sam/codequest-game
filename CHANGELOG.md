# Changelog

All notable changes to this project are documented here. Format: [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]
### Fixed
- Very quick E/Space presses now open nearby terminals directly on key-down, so an interaction is retained even when key-up arrives before the next rendered frame.
- Developer walking no longer draws standing legs under the animated legs. Each pose now separates two complete leg layers, preserves the original shoes, removes detached edge fragments and keeps the laptop/backpack on the body. Added a browser regression covering all 48 boy/girl walking frames.
### Added
- Original 3D wrist-tablet cinematic: the city camera approaches the character, articulated arms lift the device, the head turns toward its screen, and a perspective camera enters the full-screen workspace. Supports both developers, skipping, early closing, reduced motion and unavailable 3D contexts; the temporary WebGL scene is disposed after use.
- Missions and Guide tabs inside the tablet, with graded tasks retaining the device frame and a Tablet home control. Existing four-language practice, mission rules and saves remain in place.
- Explicit browser-local save copy and an independent-player browser test: two people using the same URL in separate browser profiles retain different characters, progress and tablet drafts through reload.
- Current gameplay, drone-lesson, repair-editor and tablet screenshots in the README, with a reproducible browser capture script. Removed the four unrelated planning mockups.
- A guided courier adventure in all four languages: meet Kai, predict and inspect a changing battery, preview code freely, write a repair and watch a drone delivery. Accepted repairs open a real solid courier lane; existing task IDs, saves and one-time rewards are retained. Includes contextual feedback and a free transfer exercise.
- A developer tablet opened with T or the Tablet button, with a character/tablet opening animation, editor/example/console tabs, real browser execution, keyboard tab navigation and separate saved practice drafts per language. Closing cancels an active run; practice never changes hearts, gems or missions.
- An education and adventure design plan with a city-restoration story, contextual teaching, a stranded-drone mission pilot, visible code-driven world changes and beginner playtest criteria. Recorded as the next priority; gameplay implementation is still planned.
- Logic Junction in all four languages: four lesson pages, eight missions on comparisons, if/else chains, AND/OR/NOT and nested conditions, plus the Router boss and three ordered hints. Connected district travel, per-area HUD/progression, drafts, Continue, reset isolation and dynamic world markers without changing version-1 saves. Reuses the solid campus layout with a violet district theme and decision-network signage.
- Public GitHub repository and a separate Vercel game project, with reproducible Vite build settings and ignored deployment credentials/state. Completed tasks are committed and pushed; authorized roadmap work continues automatically.
- Modern tech-city redesign: distinct boy/girl developers in hoodies with laptops and backpacks, glass office campus, street trees, metal rails, coding terminals, digital guide and Firewall server core. Updated district names, cyan/blue interface and solid planter/building/pool footprints while preserving task IDs, runners and version-1 saves. Added a browser check for boy selection, walking and Continue.
- Solid world-object footprints and swept movement collision; transparent tree/rock/fence layers with natural depth sorting; chest-front number plates; larger scrolling map and wider chest spacing. Added six articulated walking poses with planted/lifted feet and timing based on actual travel. New browser tests cover blocking, walking around obstacles, canopy transparency and the complete physical quest route.
- Fantasy-adventure redesign: tall armored knights with long legs, helmets, swords, shields, capes and four-direction walking poses; painted woodland outpost, ornate treasure chests, magical scroll and armored Gatekeeper. Updated world collisions and quest placement; browser test walks the full map and defeats the boss. Artwork and generation prompts are saved locally.
- Village visual polish: layered forest scenery, warm dirt paths, planted gardens, detailed house fronts, animated pond/lanterns/smoke/motes, a boss shrine, quest beacons and completion sparkles. Redesigned title screen, language cards, framed menus and HUD with task-progress segments; decorative animation respects reduced-motion preferences. Original local Kenney sheets are preserved.
- Playable Variable Village in Java, JavaScript, TypeScript and Python: hero creation, movement, interactions, paged lessons, eight coding tasks and a boss per language, live Run/Submit, hearts/gems, hints, retries, victory, world map and automatic saves/Continue. Includes a real JavaScript worker, content schema/loader, and browser tests for the player journey and all 36 reference programs. The first editor is a plain text area; later areas, CodeMirror and Tiled maps remain upcoming.
- Browser-save adapter with separate version-1 language slots, runtime state validation, explicit corrupt/unsupported-version results, and quota/access failure handling. Invalid writes preserve the previous save. Covered by 61 unit tests and two Chromium tests, including progress surviving reload in all four languages; gameplay autosave wiring and Continue/New screens remain upcoming tasks.
- Immutable game state and progression rules: three hearts per area, ordered task gates, difficulty-based gem rewards, boss-only hint spending, area resets that preserve found lessons and previous victories, and seven-area unlocks. Submission failures distinguish player mistakes from compiler/runner errors and ignore results from a different area. Covered by 28 new unit tests; gameplay UI remains a separate task.
- Ruflo core skill setup, local project memory/configuration and a pinned `npm run ruflo` command; setup and health notes in `docs/RUFLO.md`.
- Kenney CC0 art sheets and original licenses for village scenery, heroes, lesson scrolls, gems and bosses, with a source catalogue in `docs/ART.md`.
- Static game art preview and a Chromium smoke check for local sheet loading and valid sprite frames.
- Java runner: compiles and runs player Java in the browser (teavm-javac in a Web Worker), with compile errors (line numbers), runtime errors, output cap and endless-loop timeout. E2E tests cover what works and the known limits.
- TypeScript runner: real type-checking (strict, TS 6 compiler in a Web Worker), type errors with line and column, runtime errors mapped back to the TypeScript line, `prompt()` for input, top-level `await`, timers that behave like Node, output cap, endless-loop timeout. `import`/`export` give a clear compile error.
- `console.log` output identical to Node's (port of `util.inspect`/`util.format`, unit-tested against real Node).
- Runner workers are replaced automatically if player code changes built-ins (e.g. `Array.prototype`).
- Python runner: Pyodide (Python 3.14) in a Web Worker with `input()` support, syntax errors as compile errors (with line), friendly runtime errors (`IndexError: … (line 3)`), fresh variables, stdin and interpreter state each run, output cap, endless-loop timeout; a crashed runner is replaced automatically. Runtime files copied from npm by `scripts/copy-runtimes.mjs` (recopies when the Pyodide version changes).
- `WorkerHost`: one warm worker per language, queued runs, separate compile cap (20 s) and run timeout (5 s), warmup cap (60 s), `runnerError` for runner failures (never costs a heart). Unit-tested with a fake worker.
### Changed
- E2E tests build with `--mode e2e`; the `window.__codequest` test hook is no longer in normal builds. Test server moved to port 4317.
- Project setup: git, `.gitignore`, reference images in `docs/reference/`.
- Planning docs: PRD, Architecture, Roadmap, Decisions, Progress, Credits.
- Claude Code team: 10 subagents and 8 workflow commands in `.claude/`.
- App skeleton: Vite 8 + TypeScript 7 + Phaser 4 placeholder scene, Vitest and Playwright smoke tests, Biome lint, GitHub Actions CI.
